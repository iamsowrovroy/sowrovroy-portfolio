## ✨ Key Features

- **Multi-Page Client-Side Routing:** Dedicated pages powered by React Router DOM.
- **Modular Architecture:** Reusable components and independent page sections.
- **Dark & Light Theme:** Custom `useTheme` hook with `data-theme` on the HTML element.
- **Theme Persistence:** Saves theme preferences using localStorage, with dark mode as the default.
- **Responsive Navigation:** Mobile-friendly navbar with menu toggle.
- **Dynamic SEO Metadata:** Route-level metadata using `react-helmet-async`.
- **Social Media Metadata:** Open Graph and Twitter Card support.
- **Structured Data:** Person JSON-LD schema.
- **Search Engine Support:** Includes `robots.txt` and `sitemap.xml`.

## 💻 Getting Started

Want to explore or run this project locally? Follow these steps.

### Prerequisites

- Node.js (LTS recommended)
- npm

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/iamsowrovroy/sowrovroy-portfolio.git
```

**2. Navigate to the project directory**

```bash
cd sowrovroy-portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

### Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the Vite development server |
| `npm run build` | Build the production bundle |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run Oxlint checks |

## 📦 Production Build

To create an optimized production build:

```bash
npm run build
```

The generated production files will be available in the `dist/` directory.
